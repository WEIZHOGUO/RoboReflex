RoboReflex（机映）

The foundation for robots to integrate into human life.
Reflex as a first-class trainable object — stimulus injection × latency-constrained training × millisecond measurement
GitHub ↗ Benchmarks

Dual-pathway hard decoupling

Fast reflex and slow planning are strictly independent modules with an arbiter — no shared weights.

Latency-native metrics

p50 / p95 / p99 latency profiles, false-trigger rate, five-segment timing ledger. Others report success rates; we report delay distributions.

Take it with you

Trained reflexes export to ONNX (+ static-C reference for hard RT) — no platform lock-in.
